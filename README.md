# Grade 10 Chemistry: Test Prep

An interactive study page for Grade 10 Chemistry (redox, voltaic cells, batteries and corrosion).

- **Learn:** 10 topics, each with the rule, a worked example shown one step at a time and a quick check
- **Study guide questions:** 27 questions with full working
- **Extra practice:** unlimited randomly generated questions in 20 skills
- **Test:** unlocks once every topic is ticked; 20 fresh questions, a score, and the working for anything you got wrong
- **Tools:** a whiteboard and a built-in calculator, available on every tab

Open `index.html` in a browser. It is a single file and works offline.
